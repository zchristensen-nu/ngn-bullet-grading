# NGN Daily bullet grading

A blind side-by-side test: for 18 NGN Daily stories, graders pick between the bullets that went out in the newsletter and bullets Claude wrote from the article alone. Votes go to a Google Sheet; see [SETUP.md](SETUP.md).

- `index.html` is the whole page, with the story data inline.
- `img/` holds the story photos.
- `apps-script/Code.gs` is the Google Apps Script that stores votes.
